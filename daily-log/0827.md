## AICoding
 Ctrl + Shift + Alt + L로 질문창을 엽니다.
 변경할 영역을 드래그하여 선택한 뒤, ctrl+I로 수정창을 열어서 수정 가능
- 린팅 : 보기 좋게 정렬
---
단축어!
/explain 설명
/fix 문제를 찾아 고쳐줌
/tests 테스트 코드 생성
/doc 주석을 달아줌
/clear 대화 초기화. 엉뚱한 답이 계속 나올때 사용

- @는 무언가를 참조해서 사용
---
- // 자바의 주석
- <--! ~~ !!> html의 주석
---
- .gitignore는 git에 올리고 싶지 않은 파일이나 폴더를 지정하는 파일입니다.
- 파일은 확장자까지 적어줍니다.
- 폴더는 폴더명 뒤에 /를 붙여서 적어줍니다.
- 기능이나 목적별로 구분해서 적어둡니다
- 명령어로 받는 패키지, 아직 완성되지 않은 파일, 아이디나 비밀번호, 일련번호, API 키 등 민감정보 파일들
- *은 모든 이라는 뜻
- !는 not을 의미
---
- ⭕ 선택한 코드가 무슨 일을 하는지 비전공자가 알아듣게 설명해줘.
- 한 줄씩 말고, 전체 흐름을 3~4문장으로 먼저
- 어려운 용어가 나오면 괄호 안에 쉬운 말로
- 마지막에 "이 코드를 한 문장으로" 요약
