Object(객체) 
1. 배열(Array)
- 순서대로 값을 저장
- 집합 자료형
- 순서대로 값을 꺼낼 수 있다. (index로)
- 자바스크립트의 배열 index는 0부터 시작
- 배열의 길이는 .length 라는 속성으로 확인
- 자료형을 강제하지 않기 때문에 각 방마다 다른 자료형을 넣을 수 있습니다. 
- 배열의 크기를 넘어서는 방번호(index)를 부르면 undefined 

- 순서대로 값을 저장하는 자료구조 (선형 자료구조)
- 맨뒤에 값을 삽입 push(), 삭제 pop()
- 맨 앞(unshift, shift) 
- 중간 어딘가에 값을 넣어야 하는 경우도 있을 겁니다. (splice)
- splice(시작index, 삭제할개수, 삽입할 값)
array.splice(start[, deleteCount[, item1[, item2[, ...]]]])

let amount = "10000"; // 입력창에서 받은 값은 문자열
console.log(typeof amount);        // "string"
console.log(amount == 10000);      // true  (타입을 맞춰서 비교)
console.log(amount === 10000);     // false (타입까지 같아야 함 — 이 과정은 항상 이걸 쓴다)
console.log(amount + 500);         // "10000500" (문자열 이어붙이기 — 사고!)
console.log(Number(amount) + 500); // 10500 (숫자로 바꾼 뒤 계산 — 올바른 방법)
