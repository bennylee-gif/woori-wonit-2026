## CSS
- 외부 스타일 시트 : link 사용
- 내부 스타일 시트 : html 문서에 스타일 적용
- 인라인 스타일 : 하나씩 style ="" 속성

|postiion|설명|
|--------|----|
|static|기본값으로, 일반적인 문서 흐름에 따라 순차적으로 레이아웃 형성|
|relative|요소 본래의 위치를 기준으로 이동|
|absolute|상위 요소를 기준으로 배치|
|fixed|브라우저 화면을 기준으로 배치|
|sticky|일반 배치 상태를 유지하다가, 스크롤이 해당 지점에 도달하면 지정된 위치에 고정됨|
