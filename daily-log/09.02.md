Array (배열)
- 순서가 있는 값의 목록
- Index (0부터 시작하는 숫자)
- 허용 (같은 값 여러 번 저장 가능)
- 보장 (추가한 순서 유지)
- 순서가 중요한 데이터 나열

Set (집합)
- 중복을 허용하지 않는 고유한 값의 집합
- Value 자체
- 불가 (중복값은 자동 제거)
- 보장 (ES6+ 기준 삽입 순서 유지)
- 중복을 제거해야 하는 데이터 관리

Dictionary / Object (객체)
- Key-Value(키-값) 쌍의 집합
- Key (문자열, 숫자 등)
- Key는 불가, Value는 허용
- 미보장 (Key 순서 제어 불가)
- 속성-값 관계로 구조화된 데이터 표기
