## Object(객체) 
1. 배열(Array)의 기본 성질
- 순서대로 값을 저장/ 꺼내기
- 자바스크립트의 배열 index는 0부터 시작
- 배열의 길이는 .length 라는 속성으로 확인
- 집합 자료형 []
- 자료형을 강제하지 않기 때문에 각 방마다 다른 자료형을 넣을 수 있습니다. 
- 배열 크기를 벗어난 인덱스를 호출하면 에러가 아닌 undefined를 반환합니다.

2. 요소 추가 및 삭제 메서드
- 맨 앞에 삽입 unshift(), 삭제 shift()
- 맨뒤에 값을 삽입 push(), 삭제 pop() 
- 주간 조작 splice(시작index(필수), 삭제할 개수, 삽입할 값)
- arr.splice(2, 1) : 2번 인덱스 요소 1개 삭제
- arr.splice(1, 0, 'A') : 1번 인덱스 위치에 삭제 없이 'A' 삽입

3. JS의 sort는 기본적으로 유니코드로 정렬을 합니다.
- 배열, 문자열은 [배열], 문자열로 표시
- 문자열 순서대로 정렬
- 숫자 오름차순 (작은 수 > 큰 수): arr.sort((a, b) => a - b)
- 숫자 내림차순 (큰 수 > 작은 수): arr.sort((a, b) => b - a)

4. 특수 자료형과 NaN의 관계
- null 변환: Number(null) 실행 시 "아무것도 없음"을 나타내므로 0으로 변환됩니다.
- undefined 변환: Number(undefined) 실행 시 값 자체가 정의되지 않아 변환에 실패하며 NaN(Not a Number)을 반환합니다.
- NaN의 타입: 숫자 연산에 실패해서 나온 결과이지만, 자바스크립트 내부 분류상 데이터 타입 자체는 'number'에 속합니다.

## Set(집합): 중복을 허용하지 않는 데이터 모임
- 배열처럼 값들의 모임이지만, 동일한 값을 중복해서 저장할 수 없습니다.
- new Set([1, 3, 4, 5, 6, 6])을 실행하면 중복된 6은 하나만 남아서 {1, 3, 4, 5, 6}이 됩니다.
- set.add(값): 새로운 값 추가 (이미 존재하는 값이면 무시됨)
- set.delete(값): 특정 값 삭제
- set.clear(): 모든 값 전체 삭제(초기화)

## Object(일반 객체) : key(기본 자료형)로 value를 부르는 종류의 dictionary 타입
- Key - Value 쌍: 사전(Dictionary)처럼 Key를 이용해 대응되는 Value를 찾아내는 구조입니다.
- key는 기본자료형만 사용 가능합니다. (object, array, function은 불가)
- key의 자료형은 string, number, boolean, null, undefined, symbol이 가능합니다.
- 자동 문자열 변환: 내부적으로 Key를 문자열로 변환하여 저장하므로, 숫자 1을 Key로 넣어도 "1"로 바뀝니다.
- key는 중복될 수 없습니다. (중복된 key로 삽입하면 나중에 삽입한 값으로 덮어씌워집니다.)
- key의 순서는 보장되지 않습니다. (입력한 순서대로 출력되지 않습니다.)
- key 중심으로 움직입니다. value로 key를 찾을 수 없습니다.
- key(문패) : value(값), key : value, key:value 
- value는 모든 자료형이 가능합니다. (기본자료형, 참조자료형 모두 가능)
---
- 데이터 조작
- 추가 및 수정: dict["가"] = "가방"
    - Key("가")가 이미 있으면 기존 Value를 "가방"으로 수정합니다.
    - Key가 없으면 새 Key-Value 쌍을 추가합니다.
- 삭제: delete dict["가"]
    - 객체에서 해당 Key 항목을 삭제합니다.
    - 실행 결과(console.log(delete dict["가"]))는 해당 Key가 있었든 없었든 true를 반환합니다.
- Key 존재 여부 확인: '라' in dict
- Object 전용 메서드 Object.메서드()
- Object.keys(dict2) // key 만 array 형태로 리턴 
- Object.values(dict2) // value 만 array 형태로 리턴 
- Object.entries(dict2)  // [key, value]  array 형태로 리턴

// 은닉성 구현: #을 붙인 private 변수를 사용하여 외부에서 접근하지 못하도록 숨길 수 있습니다.

class Person2{
  // 생성자(객체가 처음 만들어질때 1번 자동으로 실행되는) 함수 
  constructor(name, age){
    this.name = name;
    this.age = age;
  }
  // Person2라는 설계도를 통해 만들어진 객체에게 Person2 자료형에만 동작하는 함수를 넘겨줌
  greet(){
    console.log(`안녕하세요! ` + this.name);
  }
}

// BankAccount 라는 은행 계좌를 관리하기 위한 class를 만들어보겠습니다.
// bankName, name, accountNumber, balance
// #을 앞에 붙인 변수는 외부에서 접근이 불가능하도록 숨길 수 있습니다.

class BankAccount{

  #balance;

    // static 이라는 클래스 변수로 클래스에서 달라지지 않는 내용을 관리하기 위한 속성을 저장합니다.
  static bankName = '우리'
  static accountNo = 0; //이 은행에 계좌를 만든 총 계좌수
  // 클래스 매서드 : static 앞에 적어서 클래스에서 필요한 동작을 만듭니다.
  static hello(){
    console.log(`어서오세요. ${this.bankName}은행입니다!
      개설이래 현재까지 ${this.accountNo}개의 계좌가 있습니다.`);
  }

  // this 라는 인스턴스 변수에 입력받은 내용 저장
  constructor(name, accountNumber, balance){
    this.name = name;
    this.accountNumber = accountNumber;
    this.#balance = balance;
    this.cusAccountNO = ++BankAccount.accountNo; //그때 계좌수
  }
  
  // 함수인걸 숨겨서 변수처럼 이 값을 파악하게 하려고
  // get -> 조회, set -> 수정
  // 인스턴스 매소드 : deposit : 입금 - 기존 balance에 새로 들어온 금액을 추가
   set deposit(amount = 0){ // setter : 값을 변경만 하는 함수
    this.#balance += amount;
  }

  // 인스턴스 메소드 : withdraw : 출금 - 기존 balance에 새로 빠져나간 금액을 제외
  set withdraw(amount = 0){ // setter : 값을 변경만 하는 함수
    this.#balance -= amount;
  }
  // private 변수의 조회만 가능하도록 작성한 getter
  // 실제로는 함수이지만 외부에서 매서드로 사용할 때 변수처럼 부르게 됩니다.
  get checkAmount(){
    console.log(this.#balance);
  }
}
