# git stash : 임시저장
- git add .
- git commit -m "fix: "
- git push origin 브랜치명

# 0904_이름2로 브랜치를 파서
- 해당 브랜치에 본인이름으로 된 마크다운 파일을 만듭니다.
- git switch -c 0904_benny2
- 내용을 적습니다.
- 그리고 commit 후
- main에 pull request를 보냅니다. 

- git fetch는 연동해줄까
- git push origin --delete <브랜치명>을 적어주시면 remote repo에서도 브랜치명이 사라집니다.

- commit 후 다른 작업이 남아있을때
- 같은 파일을 여럿이 변경해뒀을때
