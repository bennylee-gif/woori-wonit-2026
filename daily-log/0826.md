# 깃허브 명령어
- clone 사이트주소 : 사이트에 있는 내용 컴퓨터로 가져오기
- cd 파일명
- echo 파일생성
- git init 저장소 시작
- git remote add 주소별칭
- git push -u origin main
- mkdir 디렉토리명 : 디렉토리 만들기
- git add 파일명
- git commit -m "수정 내용"
- git push origin main : orgin 사이트주소 로 위에서 설정 
- git pull
- . : 모든 파일
- **: 수정내용
