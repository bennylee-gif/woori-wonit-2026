# git 사용법
- 명령어 또는 vsCode에서 형상관리
- Markdown Preview Enhanced
- cmd 창을 기본으로 사용
- 수정 전/중/후로 이동하기 위함
- feat: 새 기능
- fix: 버그 수정
- docs: 문서
- style: 모양만 변경
- refactor: 동작은 같고 구조만 개선

# vsCode
- 위에 하얀 점이 있으면 저장은 안 되고 있다는 뜻입니다. ctrl + S 해야 함

# 깃허브 명령어
- git add 파일명
- git commit -m "수정 내용"
- git push origin main
- git pull
- . : 모든 파일(수정내용)
